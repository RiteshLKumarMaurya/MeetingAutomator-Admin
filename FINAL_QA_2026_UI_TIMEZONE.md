# Meeting Automator Admin Frontend — UI/UX QA Notes

- Admin consultation settings provide start time, end time, working days, capacity, buffer, advance rules and business timezone.
- Business timezone now has an easy preset selector with a custom IANA timezone field for less common zones.
- Added subtle motion, hover, focus, navigation and login-surface refinements.
- Fixed the admin media fallback to an existing brand asset.
- Admin login uses a public Pexels editorial office image as a decorative background only; it does not imply a customer/partner relationship.


## Known browser-only console message

A browser-extension message such as “A listener indicated an asynchronous response…” is not generated by the Meeting Automator application and cannot be fixed from the app source.
